Fill the form in this order:

  1. Blog Title — The full headline of your blog post. The URL slug is auto-generated from this.
  2. URL Slug — Auto-filled from the title. Only edit if you want a custom URL (e.g. my-n8n-guide).
  3. Category — Pick the topic area that best fits your post.
  4. Status — Draft = saved but not visible on the public blog. Published = live on your site.
  5. Publish Date — Auto-set to today. Change if you want a different displayed date.
  6. Author Name — Pre-filled as "Gagan BP". Leave as-is or change.
  7. Hero Image Alt Text — A short description of the cover image for accessibility & SEO (e.g. "Screenshot of n8n workflow").
  8. Hero Image Upload — Upload the main cover/thumbnail image for this blog post.
  9. Excerpt / Card Summary — 1–2 sentence summary shown on the blog listing card. Keep it under 160 characters.
  10. SEO Meta Description — Shown in Google search results. Aim for 120–160 characters.
  11. SEO Keywords — Comma-separated keywords for this post (e.g. n8n, automation, email outreach).
  12. Content Section Builder — Build the article body using blocks: add Headings (H2/H3) for sections, Paragraphs for body text, Bullet Lists for key points, Inline Images inside the article, and Conclusion for the closing box. Use ↑↓ to reorder blocks and 🗑 to delete one.
